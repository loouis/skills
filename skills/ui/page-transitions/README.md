# Page Transition Skills

Six hand-drawn curves that swell to cover a route change, then carry their tails forward to reveal the destination. Each skill is portable and contains the same GSAP core engine, with its own selected variant.

“Suite” preserves the requested name and provisionally selects the original Tidal sweep (`wave`). The other five names map directly to their source curves.

Each package includes an interactive demo, pure geometry, a router-independent controller, an optional Astro adapter, and geometry/lifecycle tests. Colors and geometry are configurable. GSAP core is the only animation dependency.
